# Quick Note

A short note on your shelf, and optionally in the menu bar.

## Using it

Write the note, and an optional heading, in the widget's settings. The card
shows it with a **Copy** button. In the menu bar it is clipped to 14
characters, which suits a word or two ("Call Mina", "Standup 10:30").

The note is a single line of text: BarShelf has no text field inside a card,
so editing happens in settings. Duplicate the widget for more than one note.

## Permissions

None. It reads only its own settings and never refreshes on a timer.
