# BarShelf 0.7.19

## Changes

- A widget update that only takes permissions away no longer asks you to approve it again. Anything new or wider still asks. The audit log records when an approval carried over. (After the Keep Awake 0.2.0 update you had to click Allow again even though it had only dropped a command.)
