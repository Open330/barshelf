# BarShelf 0.7.33

> Unreleased. Requires macOS 14+ on Apple Silicon.

## Changes

- Wording is consistent in English and Korean. Korean instructions end in -세요 and confirmations in -할까요?, and one thing has one name (창, 새로고침, 팝업, 사본, 허용, 갤러리). Internal names are off the screen: the widget inspector shows just the version, the install confirmation drops the widget ID, and the Gallery speaks of the online widget list, not the registry. Directions point to the right place (the Shelf page, BarShelf ▸ Privacy) with one ▸ separator, and the Dock's second style is now called Cards.
