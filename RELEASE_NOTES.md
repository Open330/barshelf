# BarShelf 0.7.11

> Unreleased. Requires macOS 14+ on Apple Silicon.

## Changes

- **One look across the app.** The BarShelf window now wears the popup's
  marks: each widget shows the same coloured tile in the sidebar, the
  Shelf board, the widget inspector, Menu Bar and Privacy settings, and the
  Gallery. Gallery cards in a row end at the same height, and the Dock,
  onboarding and settings use the same spacing, corners and colours.
- **Readings stay current in settings.** The Shelf board and the Menu Bar
  settings now update as widgets refresh; they could show an old reading.
- **Your automation edits are kept.** Leaving the Automation page no
  longer discards unsaved edits, and an "Unsaved changes" mark shows when
  there are some. Turning the extension on runs the saved script; only
  Save applies edits.
- **Tidier settings.** Explanations under settings sections read as small
  notes again instead of large right-aligned text; the widget inspector
  starts at the top of its column; the switch that turns a widget off
  everywhere is called Widget On; with the BarShelf Dock off, the Dock page
  leads with profiles, which work without it.
