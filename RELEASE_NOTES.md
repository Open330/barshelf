# BarShelf 0.7.18

> Unreleased. Requires macOS 14+ on Apple Silicon.

## Changes

- The dot on the BarShelf menu bar icon that says something needs a look (a widget waiting for approval or failing) is now a red circle with a clear ring around it, in both light and dark menu bars. It used to be drawn in the same colour as the icon and read as part of it.
