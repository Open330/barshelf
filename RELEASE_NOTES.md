# BarShelf 0.7.43

> Unreleased. Requires macOS 14+ on Apple Silicon.

## Changes

- The chips in the menu bar are calmer and easier to read. Each disc keeps its widget's colour but less saturated and a little darker, with a fainter highlight, so a row of them no longer outshouts the rest of the menu bar. The icon inside is bigger (10.5 pt instead of 8.5).
