# BarShelf 0.7.29

> Unreleased. Requires macOS 14+ on Apple Silicon.

## Changes

- Pages can be edited, not only moved. On the Shelf, each page's ⋯ menu can rename the page (a name already in use merges the two), move it to the start or end, turn all its widgets off or on, merge it into another page, add a widget to it, or remove it. Removing a page moves its widgets to a page you choose; nothing is uninstalled. In the popup, the page name menu can remove the page shown.
- Empty pages. New Page on the Shelf toolbar adds a page with no widgets. It shows an "Add widgets here" card in the popup and on the Shelf until a widget arrives: Add Widget opens the Gallery and the widget you install lands on that page, or you can move one of yours there. A page you made stays when its last widget leaves.
- Menu Bar settings can add any widget, not only the ones that offer a menu bar reading. Widgets without a reading show their icon there.
- The Menu Bar settings preview now shows for Text and Items as well as Cluster, drawn as the menu bar draws it.
- In Cluster, each chip's icon and colour can be set right in its row. A chip now changes colour as soon as its widget's accent changes; before, it waited for the next change in the menu bar.
