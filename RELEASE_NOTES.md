# BarShelf 0.7.24

> Unreleased. Requires macOS 14+ on Apple Silicon.

## Changes

- The Bitwarden password prompt no longer opens under the card's menu bar popup; the popup closes first.
- Settings ▸ Privacy shows "Allowed" as soon as you allow a widget, instead of after leaving the page.
- Switches in the widget inspector and the widget builder (Widget On, Show in the menu bar, Show header, …) now have names for VoiceOver and automation.
- `barshelf install` lists a widget's password-vault permission with the others, and `barshelf agent-spec` includes the Touch ID section.
- Bitwarden 0.3.1: the locked card no longer says BarShelf never unlocks the vault.
