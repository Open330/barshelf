# BarShelf 0.7.32

> Unreleased. Requires macOS 14+ on Apple Silicon.

## Changes

- Errors and confirmations work the same everywhere. Install failures, the menu bar tooltip, VoiceOver, the Dock, the builder's Test, update checks and settings saves now say what happened and what to do, with the raw message kept behind Details. A widget button that fails shows its own message instead of marking the card's reading as stale. The Dock and the BarShelf window now show confirmations (Copied, Moved, Removed with Undo), a refresh that can't run says why, and replacing a saved Apple Dock layout or unsaved automation edits asks first.
- Settings and the Shelf look and behave the same everywhere: every page has a header with figures that say something (General, Updates and Automation got theirs), on/off rows are switches on the right, the widget inspector lines its controls up in one column, the Shelf wraps its pages instead of cutting the last one off, and the Shortcuts page now lists every key, including ⌘E, the Shelf's keys and the Dock's. The Gallery has one Everyday filter, translated packs, "Install All" buttons, labelled permission chips, and stays put after an install with a "Show in Shelf" notice.
- Permission requests say what a widget's commands do ("Read the battery level and charging state") instead of showing cut-off command lines; the exact commands are under Details. Each card lists its commands once, says what the widget is for, and uses the same list layout for one request or many.
- Waiting widgets fold to one row on the shelf, and the popup says how many are waiting with a Review… button that opens Privacy. Privacy groups them by what they could do (passwords, other apps, the internet, this Mac, notifications), and the waiting lock is easier to see in Dark Mode.
- Cards and onboarding are tidier: an empty card says what to do or what it waits for, a card's big reading keeps its place while loading, cards no longer wash the whole card in colour, the popup fades long pages and shows a page count only when the dots run out, the main button uses your accent colour in Dark Mode too, and the welcome window explains each step more clearly.
- Widgets say what went wrong and how to fix it. When a widget's data can't load, it now says why — offline, sign-in needed, too many requests, a tool that isn't installed — with a button that fixes it (open the app, get the tool, copy the sign-in command), instead of a wall of command output or a number that only looks real. Kubernetes asks you to sign in to the cluster again with `aws sso login`, GitHub Actions and Developer Inbox tell offline apart from signed out, Docker offers to open Docker Desktop or OrbStack, Tailscale and Keep Awake link to what they need, and Reminders, Stock and Weather no longer show a failure as "0", "—" or a stale price.
- Bundled widgets fixed after a review of every one: Top Processes shows real process names (it read "Te", "Xc") and can open or quit apps; Battery no longer says Charging while the Mac holds its charge, and a Mac without a battery says so instead of a red 0%; Break Reminder's ring reads "50m" (not 2972) and doesn't nag right after the Mac wakes; Today, Clock and Calendar read correctly in Korean ("2026년 11월", "목요일"); Weather tells snow and showers from storms; Exchange reads "₩1,336.60" and lets you pick the currencies; Codex Reset says "73 days ago" and has the alert its card promised; Next Meeting keeps a meeting (and Join) while it runs; Homebrew Updates finally lists the packages; Downloads New counts files that are actually new; Local Time, Network and Homebrew no longer cut off their text or buttons.
- More widgets can show a reading in the menu bar (Weather, Stock, Battery, Top Processes, Focus Timer's time left, Developer Inbox, Docker, Listening Ports and others), many gained settings for what used to be fixed (currencies, ping host, temperature unit, thresholds, a Kubernetes context, a GitHub repository — no longer ours by default), and opt-in alerts arrived where they help: low battery, a GitHub incident, a failing workflow, a site that's slow, Homebrew updates, a countdown a few days ahead.
- The bundled "Demo" page is now "Everyday", keeping wherever you had placed it. Kubernetes, Developer Inbox, Homebrew Updates and Site Monitor ask for your permission once more, because what they run has changed.
